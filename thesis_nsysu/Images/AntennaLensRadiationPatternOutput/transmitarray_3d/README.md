# Transmitarray 3D Visualization

Folder ini berisi data koordinat, gambar, dan program mandiri untuk visualisasi
geometri akuisisi transmitarray 3D.

Jalankan dari root project:

```powershell
conda activate sionna_env
python AntennaLensRadiationPatternOutput/transmitarray_3d/show_transmitarray_3d.py
```

Batas visualisasi dipertahankan pada:

- `X = [-5, 5]`
- `Y = [-30, 20]`
- `Z = [0, 55]`
